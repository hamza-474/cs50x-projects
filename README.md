## How to run

The C programs use the CS50 library and are written for the CS50 Codespace at cs50.dev.

- Open a folder in the CS50 Codespace and compile a program with make, for example: make hello
- Run it with ./hello, ./mario, ./credit, ./scrabble, ./readability, ./caesar or ./substitution
- Check a program with check50, for example: check50 cs50/problems/2026/x/me

To open the Scratch project, open week0/star-catcher.sb3 in Scratch at scratch.mit.edu.
